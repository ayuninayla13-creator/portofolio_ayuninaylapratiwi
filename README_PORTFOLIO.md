# Portfolio Ayuni Nayla — Final

## Melihat proyek tanpa hosting

Portfolio ini mendukung dua cara:
1. **Case Study / detail proyek** — recruiter dapat membaca deskripsi, fitur, teknologi, dan dokumentasi.
2. **GitHub** — source code dapat ditautkan pada setiap proyek.

Live Demo bersifat opsional. Jika sebuah proyek belum di-deploy, jangan gunakan URL localhost/127.0.0.1 sebagai link publik.

## Menambahkan GitHub / Live Demo

Pada data proyek di `script.js`, isi URL:
- `githubUrl`: URL repository GitHub.
- `demoUrl`: URL aplikasi yang sudah online.

Jika `demoUrl` belum tersedia, tampilkan proyek sebagai case study + GitHub.
