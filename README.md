# Portfolio Ayuni Nayla Pratiwi, S.Kom

Portfolio pribadi fresh graduate S1 Teknik Informatika dengan fokus pada Web Development, Data Analysis, dan System Development.

## Struktur
- `index.html` — struktur halaman
- `style.css` — tampilan/responsive design
- `script.js` — filter proyek, modal proyek, modal sertifikat, CV, dan interaksi
- `assets/ayu.jpeg` — foto profil
- `assets/certificates/` — gambar sertifikat

## Proyek
Portfolio menampilkan Prediksi Perubahan Lahan Sawah, Shop Ayy, GymPulse, dan Portfolio Website.

Setiap proyek memiliki tombol **Lihat Detail**. Modal proyek menyediakan tombol **Live Demo** dan **GitHub Repository**. Keduanya dibuat kosong sampai URL asli dimasukkan ke `projectData` pada `script.js`.

Contoh:
```js
demoUrl: "https://domain-demo-kamu.com",
githubUrl: "https://github.com/ayuninayla13-creator/nama-repository",
```

## Sertifikat
Tiga sertifikat menggunakan gambar asli yang tersedia di folder `assets/certificates/`. Kartu sertifikat dapat diklik untuk membuka detail dan gambar berukuran besar.

## Menjalankan
Cukup buka `index.html` melalui localhost (XAMPP/Live Server) agar semua aset relatif dapat dimuat dengan baik.
